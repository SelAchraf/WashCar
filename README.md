# WashCarApp

Projet mobile Expo React Native: "WashCar - Lavage auto à domicile sur réservation".

## Démarrage rapide

```bash
cd frontend
npm install
npx expo start
```

- iOS: appuyez sur i pour lancer le simulateur
- Android: appuyez sur a pour lancer l'émulateur

## Structure
- `frontend/`: Application Expo (iOS/Android)
- `backend/`: Placeholder pour l'intégration future (ex: Firebase/Supabase)

## Dépendances clés
- Expo SDK 51, React Native 0.75.x, React 18.3.x
- React Navigation (stack), NativeWind (Tailwind), DateTimePicker

## Remarques
- Données fictives (pas de backend)
- Textes UI en français
